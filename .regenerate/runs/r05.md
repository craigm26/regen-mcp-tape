## What this run taught
The fastest build of the five (10 turns), and it followed the new sentence in REQ-IF-001 exactly:
its POSIX-only tests skip on Windows and one Windows-only test skips on Linux. It still fell into
the other half of r04's trap, the half that was written down only as context in a decision: a
Python child's text output ends lines with CRLF on Windows. A requirement is what a builder acts
on; context is what it reads. The fact now sits in the requirement.
