## What this run taught
The first build on Linux, and the first clean one, on the third version of the spec. It took 18
turns. Every choice it recorded was either required by the text or already left open, most of
those open items written because r01 or r02 asked. Its notes also rediscovered, independently, the
suite bug the Linux rescore had just found: a Node.js child does not die from SIGUSR1, because Node
starts its debugger, so its own signal test uses SIGUSR2. The one Windows wrinkle was not the
program's: a stray `package.json` in the laptop's user folder makes Node print a warning on
standard error, which the spec allows and the builder's own test did not.
