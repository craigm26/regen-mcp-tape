## What this run taught
The Python build passed every suite case on both platforms, and its notes show the spec doing
its job: it translated `--redact` patterns to ECMAScript meanings (`$` as `\Z`, explicit classes
for `.` and `\s`) because r02's finding had become a sentence in REQ-RD-004. What it could not do
was see Windows. Its tests, written on Linux, assumed LF line ends from a Python child and a
SIGUSR1 that Windows does not have. The program was right; the tests did not travel. That is a
platform fact the spec now carries for the next builder. The run also showed a gap in the
method: a hung background command kept the builder's CLI from exiting after its result line.
