## What this run taught
The first blind build of the proxy passed every case on this platform in 22 turns, including
the four the earlier implementation hung on, the UTF-8 split cases and the 2 MB blobs (it used
the word-based rules, as REQ-RD-006 said to). On Windows it rediscovered why the earlier
implementation used the shell (Node refuses to spawn `.cmd` files directly) and wrote its own
`cmd /c` quoting instead. Its one real finding was again my wording: a requirement that asked
the builder to make a path resolve, when only the suite could. The signal-handling half of the
spec has not been exercised by any run yet; that needs Linux.
